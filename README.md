# 🍔 Serrone Burger - Sistema de Gestão

Este projeto é um sistema funcional focado na automação de processos de uma hamburgueria, desde o atendimento ao cliente até o fechamento financeiro.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** PHP
- **Banco de Dados:** MySQL (Relacional)
- **Interface:** HTML5 e CSS3

## 🚀 Funcionalidades Principais
- Cadastro e consulta de Clientes e Produtos.
- Registro de Pedidos vinculado ao banco de dados.
- Gestão de Vendas com filtros por forma de pagamento (Dinheiro, Cartão, PIX).
