# 🍔 Sistema de Gestão para Hamburgueria - Serrone Burger

Este é um sistema de gestão interna desenvolvido para otimizar o fluxo de pedidos e o controle de vendas de uma hamburgueria. O projeto foca em agilidade para o atendente e organização de dados para o gestor.

🔗 **[Acesse o sistema ao vivo aqui](LINK_DA_SUA_HOSPEDAGEM_AQUI)**

---

## 🛠️ Tecnologias e Ferramentas
* **Backend:** PHP 8.x (Arquitetura estruturada)
* **Banco de Dados:** MySQL (Relacional)
* **Frontend:** HTML5, CSS3 com foco em UX e JavaScript para interações dinâmicas.
* **Segurança:** Implementação de camadas de proteção contra SQL Injection.

## 🚀 Funcionalidades Principais
* **Painel de Pedidos:** Registro rápido de novos pedidos com cálculo automático.
* **Gestão de Estoque/Produtos:** Interface para cadastro e manutenção do cardápio.
* **Controle de Vendas:** Visualização organizada de todos os pedidos realizados.
* **Exportação de Dados:** Funcionalidade para gerar relatórios de fechamento de caixa.

## 🛡️ Segurança e Performance
Como projeto de um estudante de **Gestão de TI**, a segurança foi priorizada:
- **Prepared Statements:** Todas as interações com o banco de dados utilizam consultas preparadas para evitar vulnerabilidades.
- **Conexão Segura:** Configurações de ambiente separadas para proteger credenciais de acesso.
- **Interface Responsiva:** Otimizado para tablets e desktops, permitindo o uso no balcão ou na cozinha.

## 📋 Como rodar o projeto localmente
1. Clone este repositório.
2. Importe o arquivo SQL (disponível na pasta `/sql`) para o seu servidor MySQL.
3. Configure as credenciais de acesso no arquivo de conexão.
4. Certifique-se de estar usando uma versão do PHP superior à 7.4.
